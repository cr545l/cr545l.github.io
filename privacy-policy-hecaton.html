플러그인 리뷰 서비스

  • 사용자가 플러그인 리뷰 서비스를 이용(리뷰 작성·수정·삭제)하는 경우에 한하여, 개발자가 운영하는 서버에 아래 정보가 저장됩니다.
  • 수집 항목:
    • GitHub 사용자 고유 ID(숫자), GitHub 로그인 이름(공개 표시용)
    • 사용자가 작성한 평점(1~5) 및 리뷰 본문(최대 1,000자)
    • 리뷰 대상 플러그인 ID, 플러그인 버전, Hecaton 버전
    • 리뷰 작성/수정 시각

  • 수집 목적:
    • 플러그인에 대한 리뷰·평점을 사용자 간에 제공·공유
    • 중복 리뷰 식별 및 본인 리뷰 편집·삭제 권한 확인
    • 비정상 트래픽·악용 방지
  • 공개 범위:
    • GitHub 로그인 이름, 평점, 리뷰 본문, 플러그인 버전, 작성 일시는 누구나 조회 가능한 공개 API를 통해 제공됩니다.
    • GitHub 사용자 고유 ID(숫자)와 IP 주소는 외부에 공개되지 않습니다.
  • 인증 방식: 리뷰 작성·삭제 시 GitHub OAuth 토큰으로 사용자를 확인하며, 토큰 자체는 서버에 저장하지 않고 검증 목적으로만 일시적으로 사용됩니다.

Scope and Amendments

  • This policy applies to the HECATON application (the "App") and related services provided by Donghun Lim (the "Developer").
  • If this policy is amended, we will provide prior notice via the link to this policy.
  • Effective date: April 26, 2026

Collection and Use of Personal Information

  • The HECATON application itself does not directly collect, use, or share any personal information that can identify a user.
  • However, when and only when you use the optional Plugin Review Service, the information described under the "Plugin Review Service" section below is collected and processed.
  • We do not collect any personal or sensitive information such as sign-up/login data for the app itself, profiles, contacts/address book, photos/media, microphone/camera, location data, or payment information.

Plugin Review Service

  • When you use the plugin review service (submit, edit, or delete a review), the following information is stored on the Developer's server.
  • Items collected:
    • GitHub numeric user ID and GitHub login (publicly displayed)
    • Rating (1–5) and review body (up to 1,000 characters)
    • Plugin ID, plugin version, and Hecaton version
    • Creation and modification timestamps
    • Request IP address (used in logs for abuse prevention and rate limiting)
  • Purposes:
    • Providing and sharing plugin reviews and ratings between users
    • Identifying duplicate reviews and authorizing edits/deletions by the original author
    • Preventing abnormal traffic and abuse
  • Disclosure scope:
    • GitHub login, rating, review body, plugin version, and creation date are accessible through a publicly available API.
    • The numeric GitHub user ID and IP addresses are not publicly disclosed.
  • Authentication: A GitHub OAuth token is used to verify the user when submitting or deleting a review. The token itself is not stored on the server and is used transiently for verification only.

Advertising Services

  • This app does not use any advertising services and does not collect advertising identifiers or related information.

Processing of Sensitive User and Device Data

  • We do not access, collect, process, or transmit sensitive data such as health/fitness, financial/payment information, biometric data, location, microphone/camera, SMS/call logs, contacts, calendar, or files/media.

Use of Permissions

  • HECATON does not request any special system permissions for personal data collection.

Data Retention and Deletion

  • Review data (rating, body, GitHub identifier, plugin/Hecaton version, creation and modification timestamps) is retained until you delete it yourself or request deletion, for as long as necessary to provide the service.
  • You may delete your own reviews at any time through the review deletion feature in the app or the server API.
  • Server access logs (including IP addresses) are not separately collected or retained long-term by the Developer. They are handled transiently by Cloudflare in accordance with the default log policy of the Cloudflare Workers platform. Per-IP counters used for rate limiting are maintained only within a short time window (on the order of tens of seconds) and expire automatically.
  • Apart from the items above, the Developer does not store data that can identify a user or device.
  • Deletion requests and related inquiries may be sent to cr545l@gmail.com.

Sharing with Third Parties

  • The Developer does not sell any collected data to third parties.
  • To operate the plugin review service, data processing is entrusted to the following providers:
    • Cloudflare, Inc. — server hosting (Workers), database (D1), cache, and request rate limiting
    • GitHub, Inc. — OAuth token verification and user identity confirmation via API when submitting reviews
  • Items listed under the "Plugin Review Service" disclosure scope (review body, rating, GitHub login, etc.) are viewable by anyone through the public API.

Children's Personal Information

  • We do not collect personal information from children.

Security Measures

  • We apply technical and administrative safeguards such as minimizing external communications and storage.
  • The plugin review service uses HTTPS, GitHub OAuth token-based authentication, request rate limiting, and input length limits.
  • GitHub OAuth tokens are not stored on the server.

Notification Obligations

  • We will provide notice of material changes to this policy at least seven (7) days prior to their effective date via this policy document.
